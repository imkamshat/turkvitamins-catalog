TurkVitamins — каталог с фотографиями.

Загрузите index.html и папку images в корень GitHub репозитория. Не загружайте ZIP как один файл.

Фотографии добавлены только для 10 точно сопоставленных товаров. Остальные карточки показывают заглушки.

Для товаров с лекарственным статусом, включая Bitiron и Devit-3, фотографии не добавлялись в публичный каталог.
